# 工作流接口与下载目录

工作流接口要求管理员身份。

- `GET /api/v1/workflow/` 保留完整列表接口；`?summary=true` 返回卡片摘要，包含基本信息、动作的 `id/name/type`、节点状态和完成动作数。数据库查询不读取 `context` 或节点 `outputs`，也不返回动作参数、连线、事件条件和执行配置。
- `GET /api/v1/workflow/{id}` 返回完整配置和执行状态。编辑工作流信息或流程图前必须请求此接口，不能用摘要直接执行全文更新。
- `POST /api/v1/workflow/` 成功响应在 `data.id` 返回新工作流 ID；前端只读取该工作流并补入卡片，兼容旧服务未返回 ID 时刷新列表。
- 删除成功后前端直接移除对应卡片；失败时保留卡片。删除接口只读取清理定时或事件注册所需的配置，不加载运行上下文。

添加下载节点的保存路径留空（包括空字符串和纯空白）表示自动选择已配置的下载目录。显式路径仍由下载链检查；例如 `local:` 不是留空，仍会因缺少实际路径而拒绝。
