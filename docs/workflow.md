# 工作流接口与下载目录

工作流接口要求管理员身份。

- `GET /api/v1/workflow/` 保留完整列表接口；`?summary=true` 返回卡片摘要，包含基本信息、动作的 `id/name/type`、节点状态和完成动作数。数据库查询不读取 `context` 或节点 `outputs`，也不返回动作参数、连线、事件条件和执行配置。
- `GET /api/v1/workflow/{id}` 返回完整配置和执行状态。编辑工作流信息或流程图前必须请求此接口，不能用摘要直接执行全文更新。
- `POST /api/v1/workflow/` 成功响应在 `data.id` 返回新工作流 ID；前端只读取该工作流并补入卡片，兼容旧服务未返回 ID 时刷新列表。
- 删除成功后前端直接移除对应卡片；失败时保留卡片。删除接口只读取清理定时或事件注册所需的配置，不加载运行上下文。

添加下载节点的保存路径留空（包括空字符串和纯空白）表示自动选择已配置的下载目录。显式路径仍由下载链检查；例如 `local:` 不是留空，仍会因缺少实际路径而拒绝。

## RSS 名称与描述

站点 RSS 和“获取 RSS 资源”动作均保留独立 `description`，供媒体识别、过滤、下载记录及通知模板使用。

RSS 地址带 `ismalldescr=1`（兼容 `itemsmalldescr=1`）时，解析器会把名称末尾附加的 `[副标题]` 拆到 `description`，保留其中的嵌套括号。副标题后的大小、发布者标签，以及原名称中的制作组和 `&` 连接符保持原样。RSS 正文与副标题同时存在时，种子描述使用副标题。

普通 RSS 保留自身的名称、描述；如果描述与名称末尾方括号内文字完全一致，则去掉名称中的重复部分。不能明确区分的制作组、分辨率或字幕标签保留在名称中。

Anibt、动漫花园（DMHY）、萌番组（Bangumi Moe）、漫游（Comicat）、爱恋（Kisssub）和 MioBT 的资源描述可能包含完整发布正文。通知模板的 `description` 对这些站点仅显示首行有效文字，跳过图片和空段，最多保留 200 个字符，超长时加省略号。例如 `转生就是剑 第二季 / Reincarnated as a Sword Season 2 · 2 · v1`，不会再附带后面的发布说明、播放器推荐及下载按钮。

原始 RSS 和种子对象的描述完整保留，继续供识别、过滤和下载记录使用；资源名称、下载地址和大小保持原样。Mikan、Nyaa、ACG.RIP 及其他站点的描述不套用此摘要规则，通知仍按原有方式去除 HTML 标签。

例如：

```text
名称：Beyond Time's Gaze S01E43 2025 2160p HQ WEB-DL H265 HDR AAC-ADWeb
描述：国创连载 光阴之外 第43集 [玄机科技出品]
```

通知模板可分别使用 `{{ torrent_title }}` 和 `{{ description }}`，例如在名称之后添加 `描述：{{ description }}`。
