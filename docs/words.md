# 词表远程同步

本地手写词表与远程词表分开保存，识别时按本地在前、远程追加的顺序去重合并。

删除同步源并保存后，会同时清理该来源已同步的四类词表：识别词、制作组/字幕组、自定义占位符、整理屏蔽词。其他来源和本地手写内容保留；相同词条若也存在于本地或其他来源，仍会生效。删除最后一个源也会立即清理，不需要再执行“同步全部”。修改源地址同样会移除旧地址的词表。

关闭源的自动同步开关只暂停定时更新，已同步词表继续生效。旧版本遗留的、已不在同步源列表中的词表，在读取和展示时自动忽略。

## 接口行为

- `POST /api/v1/system/setting/WordsSyncSources`：保存源列表并清理已删除来源的远程内容。空列表或 `null` 表示清空源列表；保存后触发配置重载。
- `GET /api/v1/system/words/synced`：仅展示当前已配置来源的远程内容。
- `GET /api/v1/system/words/sync/status`：仅统计当前来源的同步词条。

前端成功保存后刷新远程词表；删除保存失败时恢复源卡片，并显示失败提示。
